# Portfolio App

This is the React + TypeScript application for my personal portfolio.

## Tech Stack

- React 19
- TypeScript
- Vite
- GitHub Pages

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Deploy to GitHub Pages
npm run deploy
```

## Project Structure

- `src/components/` - Reusable UI components
- `src/resumeData.ts` - Portfolio content and data
- `src/types.ts` - TypeScript type definitions
- `src/App.tsx` - Main application component
